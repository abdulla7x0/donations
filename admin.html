How to enable Delete in Google Sheets:

  1. Open your Google Sheet linked to cjpfoodfundgurramkonda.
  2. Click Extensions ➔ Apps Script.
  3. Replace all existing code in Apps Script with the backend code from code.gs.
  4. Click Deploy ➔ New Deployment ➔ Select Web App.
  5. Set Execute as: Me and Who has access: Anyone.
  6. Click Deploy and copy your new Web App URL into the input field above!
